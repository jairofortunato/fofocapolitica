## ⚖ Avisos importantes (leia antes de gravar)

1. **Tudo aqui é informação PÚBLICA do Diário Oficial do MPSC.** Mesmo assim:
   - **Iniciais (J.S.S.)**: o MP preservou; preserve também.
   - **Nomes completos**: já são públicos, podem ser citados — **mas** sempre indique o status do processo (em apuração, arquivado, ACP ajuizada etc.).
2. **"Instaurado" ≠ "condenado".** A maioria dos inquéritos NÃO termina em condenação. Use linguagem como "**investigado por**", "**suspeito de**", "**MP apura se**" — nunca "**comprovadamente culpado**".
3. **"Arquivado" não significa "nada aconteceu".** Muitos arquivamentos vêm com **Recomendação cumprida** ou **TAC firmado** — a irregularidade existiu e foi corrigida sem ação. Isso conta como vitória pública.
4. **Cuide da prescrição.** A Lei 14.230/2021 mudou a improbidade — vários casos arquivam por exigência de "dolo específico" agora. Isso é matéria-prima para conteúdo crítico ("**como a nova lei dificultou o combate à improbidade**").
5. **Tribunal de Contas (TCE/SC) é parceiro frequente.** Vários casos arquivados pelo MP estão com **ressarcimento ao erário em curso pelo TCE** — vale o segundo link.

## 📁 Estrutura de arquivos

```
mp/
├── pdfs/                   90 PDFs originais (62 MB)
├── texts/                  Texto extraído (23 MB)
├── parsed/                 JSON estruturado por edição
├── resumos/
│   ├── INDEX.md           ← você está aqui
│   ├── lotes/             9 markdowns curados editorialmente
│   │   ├── lote-01.md
│   │   ├── ...
│   │   └── lote-09.md
│   └── edicoes/           90 markdowns (1 por edição, todos os blocos)
├── parse_extracts.py      Parser Python (linha-a-linha, rápido)
├── build_markdown.py      Gerador de markdown por edição
└── download_pdfs.sh       Re-rodar download para outras datas
```

## ▶ Para reabrir o trabalho com outro período

```bash
DT_INICIO=2026-06-01 DT_FIM=2026-06-30 ./download_pdfs.sh
# depois:
for f in texts/*.txt; do
  base=$(basename "$f" .txt)
  python3 parse_extracts.py "$f" > "parsed/${base}.json"
done
python3 build_markdown.py parsed resumos/edicoes
```
